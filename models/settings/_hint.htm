Using reCAPTCHA requires an API key pair from Google

Sign up for an API key pair to use with this website. The key pair consists of a site key and a secret key, the secret key should be kept safe.

Important: The key pair version must match the reCAPTCHA version used by the site. A v3 key pair cannot be used with v2 widgets, or vice versa. When developing locally, Google provides a test key pair that always passes, or set RECAPTCHA_ENABLED=false in the environment to bypass verification entirely.
